# Модели агентов

Основной агент работает на grok-4.7 (reasoning high, fast выключен).

Любые субагенты (Task, explore, review, test-runner и другие) обязаны либо наследовать модель родителя (grok-4.7 high, без fast), либо использовать composer-2.5 без fast.

Другие модели запрещены. Это включает пункт «other models», fast-варианты и автовыбор модели.

В каждом отчёте перечисляй использованные модели.
